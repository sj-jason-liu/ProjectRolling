## 1. 核心概念

**[A1]** 玩家是片場助理，在一次 **30 秒**的正式拍攝中維持鏡頭乾淨：巡查拍攝區外圍、靠近勸離好奇路人，並搬放交通管制道具，讓車輛在入鏡前停下。完整撐過倒數且無干擾即拍攝成功；有人或車闖入則喊卡重拍。第一個原型僅驗證「看見威脅 → 趕到處理 → 守住整段拍攝」的樂趣，使用同一場景，無多關、經濟或劇情系統。

## 2. 一次拍攝的流程

1. **準備 [A2]**：無限時；顯示拍攝禁入區、路人入口、車道與停車管制放置點。玩家可移動、撿放一個交通管制道具；路人不生成、車輛停在 A。禁入區須與車道相交，管制點位於其上游且在玩家可達範圍。玩家離開禁入區後才可按「開始拍攝」。
2. **開拍 [A3]**：倒數設為 30 秒，啟用入鏡判定、路人生成與車輛 A→B 行駛。第一位路人於第 2 秒出現，之後每 4–6 秒一位、場上最多 3 位；所有入口至禁入區至少提供 4 秒反應時間。首個原型固定入口次序與間隔，重拍沿用，以便判斷難度是否公平。
3. **處理威脅 [A4]**：玩家進入路人 3 公尺範圍即自動勸離；路人返回出生點後離場，每人最多計一次成功。交通管制道具放在指定點並鬆手後生效，車輛停於入鏡區外；移走道具則恢復行駛。不依賴玩家身體或任意物理碰撞攔車。車維持 A→B、等待 5–8 秒再回 A 的循環，瞬移段須在鏡頭外。
4. **即時回饋 [A5]**：持續顯示剩餘時間；路人勸離、管制生效各有簡短提示。入鏡立即喊卡，標示肇因及位置並進入失敗結算。
5. **倒數歸零 [A6]**：無違規則成功。成功或失敗一律只結算一次：停止倒數與新生成，取消待執行生成／車輛重置，停止現有路人、車與玩家操作，關閉入鏡判定，再顯示結果。無加時、無尾波清場；結果顯示勝負、分數、星級或失敗原因。
6. **重拍 [A7]**：「再拍一次」返回準備狀態，清除路人，重設玩家、車、道具、計時及分數；不沿用上一輪的位置、冷卻或協程。成功後也可重拍挑戰評價。

## 3. 勝負、計分與初始數值

以下全部為 **[A8] 建議規則**，數值須經首次試玩調整。

| 項目 | 規則／數值 |
|---|---|
| 拍攝範圍 | 一個可視化地面禁入區，以專用觸發範圍代表鏡頭；尺寸由關卡配置確認，不直接等同遊戲攝影機視野。 |
| 成功 | 正式拍攝連續完成 30 秒，零次入鏡。搬運道具與勸離次數不是額外通關門檻。 |
| 立即失敗 | 路人、車輛或玩家的指定判定體與禁入區重疊；道具放下後若侵入也失敗。持有道具不另作重複判定。無寬限秒數；區外碰撞不判失敗。 |
| 時間邊界 | 僅判定正式拍攝的 `[0, 30)` 秒。以事件時間決定先後：到期前入鏡算失敗，恰於第 30 秒或之後不算；避免腳本更新順序決定結果。 |
| 分數 | 成功基礎 1,000 分；每位成功勸離 +100、最多 +300；車曾因有效管制停止 +200，每輪只給一次；總分上限 1,500。 |
| 星級 | 成功 1,000–1,199：1 星；1,200–1,399：2 星；1,400–1,500：3 星。失敗 0 分／0 星，可顯示已守住秒數。 |
| 防止刷分 | 同一路人／車重複觸發不加分；準備及結算階段不計分。固定威脅排程須確保至少有 2 位可勸離路人及 1 次可攔車機會，使 3 星可達。 |

**[A8 補充]** 分數獎勵主動處理，不以手速或剩餘時間計分；提早完成任務仍須守到倒數結束。30 秒取代目前預設 10 秒，是為了容納搬運與多次巡查，尚未驗證場景距離與車速是否合適。

## 5. 待使用者確認的問題

請逐項確認、修改或補充；未回覆代表尚未定案。

1. **方向與完整性（A1、A9）**：守住鏡頭、攔人攔車是否符合心中的「拍攝助理」？此單關循環是否完整，或還缺一個必須先做的核心工作？
2. **時間與節奏（A2、A3、A7）**：接受無限時準備 → 30 秒拍攝 → 結果 → 重拍嗎？原型先固定威脅排程是否合適？
3. **失敗嚴格度（A5、A6、A8）**：接受一次入鏡立即失敗嗎？玩家與落地道具也算入鏡嗎？若希望容錯，需另選「扣分並繼續拍攝」方向。
4. **路人互動（A4）**：靠近 3 公尺就自動勸離、整輪不再回頭，是否符合期望？是否必須按互動鍵才有工作感？
5. **物品與車（A2、A4）**：現有可撿物品可否定義為交通管制道具，放指定點即可停車？需否改成其他用途或攔車方式？
6. **評價與收尾（A6、A8）**：接受成功保底 1 星、勸離／攔車加分至 3 星，失敗不給分嗎？結算時所有角色停住是否合適？
7. **原型操作範圍（A9）**：先用鍵盤驗證、手機觸控另排是否可接受？若首輪就需手機試玩，應同步納入觸控操作。
